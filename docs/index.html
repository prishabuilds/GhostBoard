// 01 — overview
What is GhostBoard?
🫀
Heartbeat Monitoring
Every RTOS task reports liveness every second. The Health Monitor detects silence within 3 seconds and triggers recovery automatically.
🔍
Anomaly Detection
Sensor readings are validated in real-time against configurable bounds. Out-of-range values and corrupted packets are flagged immediately.
🛠️
Autonomous Recovery
Failed tasks are restarted without rebooting the device. Escalating retry logic handles repeat failures gracefully.
📟
Cyberpunk OLED Dashboard
128×64 SSD1306 display shows live system state, temperature, task count, fault counter, and memory usage bar with animated state transitions.
📝
Persistent Logging
Timestamped structured logs written to Serial and SD card. Format: [TIME] [MODULE] [SEVERITY] MESSAGE
💀
Fault Injection
Simulate real hardware/software failures at runtime via Serial commands. Freeze tasks, corrupt data, stall communications — and watch GhostBoard recover.

// 03 — tasks
RTOS Task Descriptions
Health Monitor
Core 0  |  500ms cycle
PRIO 8
Central nervous system. Polls heartbeat timestamps, validates sensor data bounds, checks stack watermarks, issues recovery commands, and feeds the hardware watchdog.
Recovery Manager
Core 0  |  event-driven
PRIO 7
Blocks on fault semaphore. On wake: drains recovery queue, restarts tasks (attempt 1), reinitializes modules (attempt 2), or triggers soft reboot (attempt 3).
Sensor Task
Core 1  |  1s cycle
PRIO 5
Reads NTC thermistor via 12-bit ADC. Converts raw values to °C using Steinhart-Hart equation. Pushes SensorData_t packets to queue. Reports heartbeat every cycle.
Comm Task
Core 1  |  2s cycle
PRIO 4
Simulates UART/WiFi/MQTT telemetry. Serializes sensor data to JSON. Implements 3-attempt retry with 500ms delay. Simulates 5% random packet loss.
Logging Task
Core 1  |  continuous
PRIO 3
Drains log queue continuously. Writes timestamped entries to Serial (always) and SD card (if mounted). Flushes SD every 10 entries.
OLED UI Task
Core 1  |  250ms cycle
PRIO 2
Drives 128×64 SSD1306 over I2C. Displays system state, temperature, fault count, memory bar. Animates: blink (NERVOUS), invert flash (CRITICAL), scrolling dots (RECOVERING).
// 04 — state machine
System States
✓
HEALTHY
All tasks reporting heartbeat. Sensor data within bounds. Green LED on. Normal operation.
!
NERVOUS
First heartbeat miss detected. Yellow LED blinking. Recovery attempt 1 queued.
✕
CRITICAL
Escalation threshold reached. Red LED on. Buzzer beeps. Recovery attempt 2 or 3 in progress.
↻
RECOVERING
Recovery command issued. Yellow LED on. OLED shows scrolling dots. Awaiting heartbeat restoration.
// fault injection — serial commands
Command Fault Injected GhostBoard Response
F1 SensorTask frozen Heartbeat stops → detected after 3s → task restarted → HEALTHY restored
F2 Corrupt sensor data Invalid packets queued → HealthMonitor raises WARNING log entries
F3 CommTask stalled Comm heartbeat stops → recovery restarts communication module
F0 Clear all faults All fault flags reset → system returns to HEALTHY state
